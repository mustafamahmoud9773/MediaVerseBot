# MediaVerse Bot 🎬🎮

بوت Telegram للبحث عن الأفلام والمسلسلات والألعاب وإظهار معلوماتها.

## المصادر

- TMDB: الأفلام والمسلسلات والممثلون والشخصيات وشركات الإنتاج وتواريخ الإصدار.
- RAWG: الألعاب، المطورون، الناشرون، المنصات، تاريخ الإصدار وفريق التطوير.

## 1) إنشاء البوت

من Telegram افتح `@BotFather` ثم:
`/newbot`

انسخ التوكن وضعه في `.env`.

## 2) مفاتيح البيانات

أنشئ حسابًا في TMDB وخذ **API Read Access Token** من إعدادات API.
أنشئ حسابًا في RAWG وخذ API key.

لا تضع أي مفتاح داخل الكود أو GitHub.

## 3) التثبيت على Kali / Linux

```bash
mkdir MediaVerseBot
cd MediaVerseBot
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python3 bot.py
```

## 4) الاختبار

أرسل للبوت:

- `Interstellar`
- `The Batman`
- `GTA VI`
- `The Witcher 4`

سيظهر لك الاختيارات، ثم التفاصيل.

## ملاحظة مهمة

موعد الإصدار المعروض يعتمد على البيانات التي ترجعها واجهة المصدر. لا يتم اعتبار الأخبار أو التسريبات موعدًا رسميًا في هذه النسخة.

TMDB يتطلب الالتزام بشروط الاستخدام والإسناد عند استخدام بياناته/صوره.
RAWG يتطلب مفتاح API وإسناد المصدر وفق خطة الاستخدام.

النسخة التالية يمكن أن تضيف:
- أخبار حديثة من مصادر محددة
- ترجمة عربية للبيانات
- صور الشخصيات
- صفحة مستقلة لكل شخصية
- إشعار عند تغير موعد إصدار لعبة
- قاعدة بيانات SQLite وكاش
- لوحة Admin
